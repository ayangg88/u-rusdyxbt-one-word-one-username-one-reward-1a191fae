## The entry

One word and nothing else: the entrant's own make.fun username.

`main.py` writes that single username to `/output/entry.txt` — eight
characters, no trailing newline, no explanation, no links, no pitch.
The sealed gate needs UTF-8 text of 1 to 30 characters, and the judge
then reads the username two at a time against the other entries.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
